明日方舟基建排班与全动态收益测算器 (R.I.I.C-Calculator)
===================================================

【使用说明】
1. 本程序为解压即用整合包，无需安装 Node.js、无需手动启动 Web 服务。
2. 双击运行当前目录下的「R.I.I.C-Calculator.exe」即可直接打开桌面窗口。
3. 请保持当前目录各依赖库与「dist」资源文件夹完整，请勿移动或删除相关文件。

【系统要求】
- Windows 10 / Windows 11 (64 位)
- 系统自带 Microsoft Edge WebView2 运行时（Win10/11 通常默认内置）
  若启动提示缺失运行时，可前往微软官方下载安装：
  https://developer.microsoft.com/en-us/microsoft-edge/webview2/

【功能简介】
- 排班编辑与可视化：支持导入 Mower JSON / 二维码排班图，支持自由修改设施等级（252/333/153 布局）。
- 全动态模拟仿真：参考 Mower alpha 的任务、换班与休息流程计算；综合收益采用 82 口径。跑单仅支持理想模式，保留订单任务唤醒，不临时换入跑单干员、不计跑单等待或心情消耗；常规换班、收取和无人机任务仍参与模拟。
- 排班与搜索：支持组合草案、自动排班和长期收益比较；运行时检查休息与心情，避免普通生产干员以 0 心情进驻。
- 干员库：导入后，库内干员作为闲置候选；未导入时，以全体干员作为闲置候选。已在岗干员无需列在闲置库中。
- 默认条件：生产材料库存无限；Party Time 线索交流固定关闭。无人机、休息阈值等可在计算设置中调整。

导入闲置库后按库内干员的精英阶段、等级使用已解锁技能；未完成的模拟显示错误并保留诊断。模拟的游戏识别与点击耗时采用明确假设，结果不等同于实际账号逐帧运行。
