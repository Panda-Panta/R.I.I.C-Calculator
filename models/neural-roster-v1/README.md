# 神经网络排班首版实验模型

这是独立开发分支中的 **实验检查点，不是默认排班算法，也不是可替代启发式教师的生产模型**。

## 已验证能力

- 使用 CPU 训练的共享 MLP 自回归选择主班与普通替班，而非给整张候选表排序。
- 每张 243 表由模型选择 52 个位置，4 个宿管固定；不使用启发式补全失败输出。
- 干员库规模 100、200、300、400，每个规模独立划分一个训练、验证、测试家族。练度按固定随机规则生成，但书始终在库且练度不强制精二。
- 4 个训练家族提供 208 个决策样本；60 个 epoch、12,480 次真实梯度更新。交叉熵从 5.1397 降至 3.5359。
- 所有教师及生成结果都完成 24 小时预热＋72 小时统计。12 次教师仿真、24 次独立生成仿真，共 36 次不同仿真；32 行比较包含复用的 8 行教师结果，不重复计算仿真数量。

## 文件及使用

- `checkpoint.json`：v2 模型封装，包含权重、模型／数据／推理规则来源校验。
- `manifest.json`：原训练来源、模拟配置及家族摘要。原始样本、教师数据和完整工作区未纳入代码仓库；可通过固定命令重新生成。
- `evaluation.json`：精简评估证据与每组结果。
- [训练与推理命令](../../scripts/neural/README.md)：输入格式、超时、取消、恢复及兼容说明。

```sh
node scripts/neural/run.mjs infer --checkpoint models/neural-roster-v1/checkpoint.json --scenario models/neural-roster-v1/example-scenario.json --output decoded.json
```

附带的 `example-scenario.json` 是固定的合成 100 人库示例，不是私人账号数据。替换为新输入时，场景 JSON 需要真实 `workspace` 和 `entries`，以及预先指定的宿管／Free 休息位。推理输出明确标记未进行收益模拟，必须另用计算器检验，不能把 `complete` 当作收益或长期疲劳验收。

## 限制与后续

仅覆盖单体／中性技能课程、243 布局和非常少的训练家族；暂不支持跨设施原子组合、宿管学习、任意已有复杂策略或全目录生成。下一阶段应增加**新训练家族**和组合动作，并预先保留新的测试集，不能反复调参拟合本测试集。不得将本模型自动启用为默认算法。

模型文件是原实验 v1 封装的显式 v2 元数据迁移：原权重不变，验证所有推理源码合同一致，并确认独立推理与原留出结果完全相同。原训练来源与当前运行来源分别保存，不把旧实验冒充由新脚本重跑。
