# v1.1.0

## 更新内容

- 新增命名设施布局预设，统一干员导入入口。
- 优化长期模拟甘特图的计算与密集区块显示，并在 24 小时视图折叠日志甘特图。
- 简化产出结果卡片，恢复制造站赤金总价值展示，隐藏贸易订单内部明细。
- 修复可露希尔、佩佩订单的虚拟赤金统计，以及无人机耗尽后贸易站反复尝试加速的问题。
- 修复专职跑单干员从贸易替换位选取的问题，并减少 Mower 宿舍重复重排与立即返回循环。
