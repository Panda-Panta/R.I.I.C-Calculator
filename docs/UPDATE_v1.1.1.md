# v1.1.1

## 更新内容

- 自动排班散件先匹配设施与配方，再按干员实际已解锁技能的生效效率选择人员，取消常用干员名单的优先级。
- 主力与普通替补均按实际练度选取技能，保留完整组合、人员占用及替补唯一性约束。
- 修正候选评分缓存，避免沿用其他练度、设施等级或配方的评分。
- 修正 CI 桌面便携包的资源路径，并增加压缩包内资源引用检查。
- 修正 Windows 便携包的中文头像文件名编码，并增加资源文件名完整性检查。

## 下载

Windows x64 便携版：`R.I.I.C-Calculator-Windows-x64-Portable.zip`。解压后运行 `R.I.I.C-Calculator.exe`，并保持 `dist` 目录完整。可用 `SHA256SUMS.txt` 校验下载文件。
