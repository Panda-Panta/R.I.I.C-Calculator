# 方法07：离散 GP + Expected Improvement

本原型提供 `solve(problem, *, seed=42, budget=16)`，只改本方法、独立测试和本说明；调优证据独占 `artifacts/roster-method-validation-20261028/iterations/m07/`。依赖环境已安装的 numpy、scipy；不安装 SMAC/BOCS，不改 `src/`。

## 原文与本实现的关系

- [SMAC3 原文 §2.1–2.4](https://jmlr.org/papers/volume23/21-0888/21-0888.pdf)：包含多种代理模型、采集函数和强化配置；低维连续黑盒的一个预设使用 GP + Matérn 5/2 + EI，结构化配置的其他预设使用 RF/logEI。本方法只复用“已观测值更新代理及采集函数”的 BO 原理，使用分类 one-hot 上的固定 RBF 核，无 SMAC 配置空间、RF、强化竞赛、截尾插补或包级复现。
- [BOCS 原文 §3](https://proceedings.mlr.press/v80/baptista18a/baptista18a.pdf)：对二元变量交互使用稀疏贝叶斯回归和 horseshoe 先验，后验采样后优化采集问题，包含 SDP 求解。本方法使用 GP/EI，不实现其二次交互回归、先验采样或 SDP，不称为 BOCS 实现。
- REPORT 第7节建议先尝试有限策略参数、使用合法解码、训练与最终验证分离。本方法直接服从公共有限域契约，保留原生 F 为黑盒；不能由算法核测试推断游戏排班或实际收益。

## 实际算法

1. 仅依据公开 domains、结构约束和有限排程检查构建候选集。笛卡尔域不超过4096时检查全域；更大时使用最多1024个合法候选，包括初始表邻域及固定种子随机点，邻域最多占一半以保留全域随机探索。整个过程不查询 F。排程检查抛出未完成异常时显式记录 `UNKNOWN`；不当作 `INFEASIBLE`，也不声明完整域证据。
2. 初始表合法时先查询它，独立记录基线。初始设计默认最多3次：保留一个公开G冠军，再按与已查询点的最小 Hamming 距离探索；同G时也用结构距离，平局使用指定 seed。公共cheap接口缺失的独立算法替身仍可只用多样性设计。初始表不合法、检查未知或预算为0时保留各自状态。
3. 只收集本次 `evaluate(..., fidelity='full')` 的 `valid=True`、有限数值分数。无效、未完成或非完整保真结果记 `score=None`，消耗查询预算但不变成0、不进入模型。
4. 每次初始设计后的选点，重新拟合 exact GP。输入是公开分类变量 one-hot，固定 RBF 长度为 `sqrt(变量数)`；输出均值和尺度仅从已查询有效 F 计算。噪声对角量为 `1e-6`，没有数据驱动核超参数调优。
5. 最大化 `EI = (mu-best-xi) Phi(z) + sigma phi(z)`，`z=(mu-best-xi)/sigma`，`xi=0.01*已观测F尺度`。在未查询合法候选中取最大EI，查询后再更新模型。每步记录训练查询编号、训练数量、后验均值/标准差、EI及阶段；无有效样本时继续探索，不虚构后验。
6. 总调用数受方法 budget 和 oracle.remaining 共同约束；每个候选只查一次。返回的是本次实际有效/full观测中的最高 F，候选池耗尽即停止。

公开 `metadata['m07_bayes']` 可设置 `kernel`（`rbf` / `additive` / `mixed`）、`acquisition`（`ei` / `ucb`）、`xi_factor`、`ucb_beta`、`length_scale_multiplier`、`initial_design_size`、`initial_strategy`（`cheap_then_diverse` / `diverse`）、`cheap_mean`。mixed核为0.5倍分类加性核、0.3倍成对交互核和0.2倍RBF的半正定混合。可选cheap_mean只从已查询F拟合G的仿射系数，不以全域G充当F标签；G归一化只用公开便宜值。最终默认保留RBF/EI及常数均值，因为本轮原生调优没有观察到复杂代理改善最终F。

`diagnostics.candidate_pool.feasibility_checks` 分别保存可行、不可行和未知数量及未知向量/原因。若未知候选使候选域无法完成检查，仍保留合法基线及其他已验证F；候选耗尽时返回 `public_feasibility_incomplete`，不返回全域不可行或最优证明。

这些测试只证明当前核和契约行为，不证明在RIIC上优于随机搜索、具有统计样本效率优势、在大域中找到全局最优、跨场景泛化，或真实游戏运行正确。大域候选池不完整，即使枚举完池也不是全域最优证书。当前使用一次固定seed的完整F；噪声重采样、独立留出场景和多个seed的预算曲线由主运行器另行评估，不能用已用于选优的查询替代留出验证。
